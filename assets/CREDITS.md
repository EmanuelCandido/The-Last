# Créditos de assets

Feito para o projeto:

- texturas: `tools/generate_textures.py`;
- sons sintéticos (vento, folhas, fogo, caverna, insetos, pássaros, corvos, pica-pau, lobo, gotas, árvore caindo, bufo do cervo, guincho do coelho): `tools/generate_sounds.py`;
- goblin: `models/goblin/source/` (blender-agent + polimento procedural no Blender).
